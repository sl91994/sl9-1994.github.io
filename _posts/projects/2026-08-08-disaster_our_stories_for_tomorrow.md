## 概要

- **アプリ名:** 「`被災体験アーカイブス | Our Stories for Tommorow`」
- **開発人数:** 2人

災害を経験した方の言葉を集め，誰でも読める形で残すためのアーカイブです．
皆様の被災体験を公開・共有することで，今後の防災行動や意識の向上に役立ててもらうことを目指しています．

- 匿名で投稿でき，アカウント登録は不要
- 投稿は運営の目視承認を経てから公開
- 投稿者は「編集キー」で自分の投稿を後から修正・削除できる

## 開発意図

**既存の問題点**

- 災害に関する情報は，SNSや各報道機関等に散逸しており，災害に備えるために過去の体験談を見たくても情報が発見しづらい．
- 災害の情景を映した映像や写真は，報道機関等が独占所有していることがある．
- その情報に関して連絡・取材をしたくても，連絡先が不明なことがある．
- ディープフェイクや偽の被災情報が大量に出回っている．

私は，災害に関する情報は誰もが見れるものであるべきであり，アカデミアの観点からもパブリックにするべきだという考えを持っています．(適切にライセンス表記をしたうえで)

そのため，個人が体験談を投稿でき，だれもがその情報を見ることのできるプラットフォームがあるべきではないかと思い，開発しました．

特に問題視したのは，虚偽の被災状況についてです．  
災害が発生した直後，SNSなどでは被災状況を知ることのできる有益な情報が流れてきます．  
しかし，中にはインプレッション稼ぎや悪意のある投稿者によって作られた虚偽の情報が流れてくる場合も多く存在します．(特に現在ではAI生成によるディープフェイクが多い)

このプラットフォームにおいて，投稿を即時反映せず管理者の認証を必須にしたのは，これらの問題を危惧したためです．  
また，デジタルネイティブではない世代にも経験談を投稿してもらうため，手間となるアカウント登録を排除しました．

## 主な機能

| タブ             | コンポーネント | 内容                                                                  |
| ---------------- | -------------- | --------------------------------------------------------------------- |
| 体験談を読む     | `ReadView`     | 年表・条件絞り込み・キーワード検索・ページング付きの一覧と詳細表示    |
| 地図から探す     | `MapView`      | 発災時にいた場所から探す                                              |
| 教訓の言葉       | `WordView`     | 投稿本文のワードクラウド                                              |
| 体験を投稿する   | `WriteView`    | 全9セクションの投稿フォーム．写真・動画リンクの添付，下書きの自動保存 |
| 投稿の修正・削除 | `EditView`     | 編集キーによる本人照合と，投稿の読み込み・修正・削除                  |
| 利用ガイド       | `GuideView`    | 投稿の流れ・注意事項の案内                                            |
| 利用規約         | `TermsView`    | 利用規約本文                                                          |

### 読む側の機能

- **年表から選ぶ**: 1954年以降の災害マスタから災害名を選んで絞り込み
- **絞り込み**: 災害の種類 / 災害名 / 都道府県 / 年齢層 / 性別 / 同行者 / 被害 / 避難状況 (複数選択可能)
- **キーワード検索**: 自由記述カラム全体に対する部分一致 (空白区切りの AND 検索)
- **並び替え**: 新しい順 / 古い順 / 記述が長い順
- **詳細表示**: 添付写真のギャラリー・拡大表示，動画リンク，写真ごとの利用条件 (ライセンス) 表示

### 投稿側の機能

- 災害の種類 (地震・津波 / 火山 / 風水害) に応じて **設問の文言・必須項目・選択肢が切り替わる** フォーム定義
- 地震・津波では「津波を体験した」場合のみ津波専用の追加設問を表示
- 写真は最大 6 枚 / 動画リンクは最大 3 件
- 写真はアップロード前にブラウザ内で **長辺 1920px へのリサイズ + WebP 再エンコード** を行い，Exif 等のメタデータを落とす
- 写真 1 枚ごとに利用条件 (転載禁止 / CC BY / CC BY-SA / CC BY-NC / CC0) を選択
- 入力内容は `localStorage` に自動で下書き保存 (写真，規約同意・権利確認のチェックは保存しない．30日で失効)
- 投稿完了時に **編集キー (UUID)** を発行．端末側の控えは3日で自動削除

## 技術スタック

### フロントエンド

| 種別     | 採用技術                                                      |
| -------- | ------------------------------------------------------------- |
| UI       | React 19 (関数コンポーネント + Hooks，状態管理ライブラリなし) |
| 言語     | TypeScript 6                                                  |
| ビルド   | Vite 8 + 自作 `minifyHtml` プラグイン                         |
| スタイル | Valilla CSS，フレームワークなし                               |

### バックエンド

| 種別         | 採用技術                                                |

| クライアント | `@supabase/supabase-js` v2                              |
| DB 拡張      | `pg_net` (Storage API 呼び出し), `pg_cron` (定期掃除)   |

| 種別           | 採用技術                                                                      |
| -------------- | ----------------------------------------------------------------------------- |
| パッケージ管理 | pnpm                                                                          |
| 開発環境       | Nix Flakes + direnv (Node 24 / corepack / supabase-cli)                       |
| Lint           | ESLint (flat config) + typescript-eslint + react-hooks + react-refresh        |
| ホスティング   | 静的配信 + `public/_headers` によるセキュリティヘッダ (Cloudflare Pages 想定) |
