# 被災体験アーカイブス (Our Stories for Tomorrow)

地震・津波，火山，風水害を経験した人の言葉を集めて，誰でも読めるかたちで残すためのアーカイブサイトです．

[被災体験アーカイブス](https://our-stories-for-tomorrow.com/)

- 匿名で投稿でき，ログイン (アカウント登録) は不要
- 投稿は運営の目視承認を経てから公開
- 投稿者は「編集キー」で自分の投稿を後から修正・削除できる

---

## 主な機能

選択中のタブは `localStorage` に保持されます．

| タブ | コンポーネント | 内容 |
| --- | --- | --- |
| 体験談を読む | `ReadView` | 年表・条件絞り込み・キーワード検索・ページング付きの一覧と詳細表示 |
| 地図から探す | `MapView` | **開発中** (発災時にいた場所から探す．) |
| 教訓の言葉 | `WordView` | **開発中** (投稿本文のワードクラウド) |
| 体験を投稿する | `WriteView` | 全9セクションの投稿フォーム．写真・動画リンクの添付，下書きの自動保存 |
| 投稿の修正・削除 | `EditView` | 編集キーによる本人照合と，投稿の読み込み・修正・削除 |
| 利用ガイド | `GuideView` | 投稿の流れ・注意事項の案内 |
| 利用規約 | `TermsView` | 利用規約本文 |

### 読む側の機能

- **年表から選ぶ**: 1954年以降の災害マスタから災害名を選んで絞り込み
- **絞り込み**: 災害の種類 / 災害名 / 都道府県 / 年齢層 / 性別 / 同行者 / 被害 / 避難状況 (複数選択)
- **キーワード検索**: 自由記述カラム全体に対する部分一致 (空白区切りの AND 検索)
- **並び替え**: 新しい順 / 古い順 / 記述が長い順
- **詳細表示**: 添付写真のギャラリー・拡大表示，動画リンク，写真ごとの利用条件 (ライセンス) 表示

### 投稿側の機能

- 災害の種類 (地震・津波 / 火山 / 風水害) に応じて **設問の文言・必須項目・選択肢が切り替わる** フォーム定義
- 地震・津波では「津波を体験した」場合のみ津波専用の追加設問を表示
- 写真は最大 6 枚 / 動画リンクは最大 3 件
- 写真はアップロード前にブラウザ内で **長辺 1920px へのリサイズ + WebP 再エンコード** を行い，Exif 等のメタデータを落とす
- 写真 1 枚ごとに利用条件 (転載禁止 / CC BY / CC BY-SA / CC BY-NC / CC0) を選択
- 入力内容は `localStorage` に自動で下書き保存 (写真，規約同意・権利確認のチェックは保存しない．30日で失効)
- 投稿完了時に **編集キー (UUID)** を発行．端末側の控えは3日で自動削除

### 実装予定の機能

- 多言語対応
- 国別の災害への対応
- 地図から探す機能
- 教訓の言葉
