`exatlon()` 関数では，入力された文字列を，比較のために先ほどの `1152 1344 1056...` のような形式に暗号化する処理が書かれています．具体的には，入力文字列をasciiコードに変換し，1文字毎のascii数値を **4bit 左シフト (2^4=16倍)** したものを返しているようです．

そのため，`1152 1344 1056...` をスペース毎に **16で除算** した数値をasciiに基づいて元の文字に変換することでFlagが入手できます．

## 復号

**decrypt.py**
```python
#!/usr/bin/env python3

# 暗号化された数字列
encrypted_data = "1152 1344 1056 ..."

# スペースで分割して整数のリストに変換
numbers = [int(x) for x in encrypted_data.split()]

# 各数値を16で割り，chr()でASCII文字に変換して結合
flag = "".join(chr(num // 16) for num in numbers)

print(f"[+] Decrypted Flag: {flag}")
```
